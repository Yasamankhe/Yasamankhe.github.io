Analog | Embedded Systems

Smart Temperature Monitoring & Control System

Completed

I built a temperature monitoring and control system around an NTC thermistor, Wheatstone bridge, instrumentation amplifier, and Arduino. I fitted a four-coefficient Steinhart-Hart model in Python to convert the measured resistance into temperature and calibrated the final system to about ±0.1°C.

±0.1°C calibrated accuracy 10-bit ADC PWM fan control

I also used comparator and logic circuitry to control different temperature ranges, and I used a 555 timer to generate the PWM used for the half-speed fan mode.

Analog Design Thermistor Wheatstone Bridge Instrumentation Amplifier Arduino 555 Timer Python Calibration

PVDF Piezoelectric Film Characterization

Research

I developed an experimental setup using a VNA, oscilloscope, and function generator to characterize PVDF piezoelectric films. I compared the measured impedance and resonance behavior against analytical predictions and investigated an approximately 18% shift in resonance frequency.
