Smart Temperature Monitoring & Control System

I built a temperature sensing and control system around an NTC thermistor, Wheatstone bridge, analog amplification, and Arduino. I fitted a four-coefficient Steinhart-Hart model in Python, used those coefficients in the embedded firmware to convert measured resistance into temperature, and displayed the result on an LCD. I also built analog control circuitry using comparators, logic gates, and 555 timers to control different motor operating modes.

02

Temperature Measurement

In the Arduino firmware, I first read the amplified analog signal using the 10-bit ADC. I convert the raw ADC value back into voltage, account for the measured offset and amplifier gain, then reconstruct the thermistor voltage inside the bridge.

From that voltage I calculate the thermistor resistance using the known fixed bridge resistor and bridge supply. The resistance is then passed into the Steinhart-Hart model to calculate temperature in degrees Celsius.

ADC
The Arduino reads the analog signal on A0 with a 0 to 1023 ADC range referenced to 5 V.
Bridge Supply
I used the measured bridge supply value of 9.004 V in the resistance calculation.
Fixed Resistance
The firmware uses a 298 kΩ fixed resistance in the bridge model.
Amplifier
I compensate for the amplifier gain of 1.1 and the measured voltage offsets before calculating resistance.
Output
The calculated temperature is displayed to two decimal places on a 16 × 2 LCD and also sent through the serial interface.
03

Steinhart-Hart Calibration

The NTC thermistor has a nonlinear resistance-to-temperature relationship, so I fitted a four-coefficient Steinhart-Hart model instead of using a linear approximation.

In Python, I used the resistance-temperature dataset, converted Celsius to Kelvin, calculated reciprocal temperature, and used SciPy curve_fit() to extract A, B, C, and D.

Four-coefficient model

The firmware evaluates 1/T = A + B ln(R) + C ln(R)² + D ln(R)³, then converts the result from Kelvin to Celsius.

04

Code

The Python script generates the Steinhart-Hart coefficients from the resistance-temperature data. I then use those same coefficients in the Arduino firmware to calculate temperature from the physical sensor measurement.

Arduino / C++
Temperature Measurement Firmware
thermometer.ino 
#include <LiquidCrystal.h>
#include <math.h>

const int RS = 8, EN = 9, D4 = 6, D5 = 5, D6 = 4, D7 = 3;
const int SENSOR_PIN = A0;

// 4-coeff Steinhart-Hart:
// 1/T = A + B*ln(R) + C*ln(R)^2 + D*ln(R)^3

const float SH_A = 0.001128547485576f;
const float SH_B = 0.000234281399318f;
const float SH_C = -0.000000012298570f;
const float SH_D = 0.000000087935152f;

const float VCC = 5.0f;
const float ADC_MAX = 1023.0f;

const float VIN_BRIDGE = 9.004f;
const float R_FIXED = 298000.0f;
const float VB_BRIDGE = 0.01502f;
const float AMP_GAIN = 1.1f;

LiquidCrystal lcd(RS, EN, D4, D5, D6, D7);


float resistanceToTempC(float R) {

    float lnR = log(R);

    float invT =
        SH_A
        + SH_B * lnR
        + SH_C * lnR * lnR
        + SH_D * lnR * lnR * lnR;

    return (1.0f / invT) - 273.15f;
}


void setup() {

    Serial.begin(9600);

    lcd.begin(16, 2);
}


void loop() {

    int adcRaw = analogRead(SENSOR_PIN);


    float vOutAmp =
        (adcRaw * VCC) / ADC_MAX
        + 0.022f;


    float vTherm =
        VB_BRIDGE
        + (vOutAmp / AMP_GAIN);


    float R =
        (R_FIXED * vTherm)
        / (VIN_BRIDGE - vTherm);


    float tempC =
        resistanceToTempC(R);


    lcd.setCursor(0, 0);

    lcd.print("Temp: ");

    lcd.print(tempC, 2);

    lcd.print((char)223);

    lcd.print("C   ");


    Serial.println(tempC, 2);


    delay(200);
}

05

Comparator Control Logic

For the motor-control portion, I used two comparator thresholds at 2 V and 3 V. Their outputs divide the input into three operating ranges.

Input Range Comparator State Motor Behavior
Vin < 2 V A = LOW, B = LOW Motor runs continuously at full speed.
2 V < Vin < 3 V A = HIGH, B = LOW Motor runs at approximately half speed for about 15 seconds.
Vin > 3 V A = HIGH, B = HIGH Motor is turned off.

I combined the comparator outputs with AND, OR, and inversion logic to generate the motor-control signals for the different operating regions.

06

555 Timer Control

I used two 555 timer circuits for two different jobs. A monostable circuit controlled the duration of the timed mode, while an astable circuit generated the approximately 50% PWM used for half-speed motor operation.

Monostable

~15 Second One-Shot

I used a 1000 µF timing capacitor and adjustable resistance to target a 15 second output pulse. Because the real electrolytic capacitor tolerance shifted the timing, I tuned the resistance until I measured approximately 15.1 seconds.

Astable

~50% PWM

I separated the charge and discharge paths with diodes so I could control their timing more independently and obtain a duty cycle close to 50%.

One-Shot Equation
I used t = 1.1RC as the starting point for selecting the monostable timing components.
Initial Result
The physical timing was longer than the theoretical calculation because of component tolerance.
Final Tuning
I reduced the adjustable resistance until the output timing was approximately 15.1 seconds.
PWM Network
The astable design used approximately 101 kΩ in the charging path and 100 kΩ in the discharge path, giving about 50.2% calculated duty cycle.
Calculation followed by physical tuning

I used the theoretical RC calculation to choose the initial component values, then adjusted the physical circuit based on the measured timing.
